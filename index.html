Shader validation, everywhere

Edit HLSL, GLSL or WGSL below and get diagnostics, hover and completion as you type. This is shader-language-server, the server behind the shader-validator VS Code extension, running locally as Rust compiled to WebAssembly.

Same server as VS Code

This is the WASI build the extension uses on VS Code for the web. As there, HLSL is validated with glslang, as DXC does not compile to WASI. The desktop extension uses DXC.

Runs in web workers

The server is built for wasm32-wasip1-threads: each of its threads runs in a worker, sharing one memory. A small WASI host feeds it LSP messages from ace-linters.

Want more?

The extension adds goto, inlay hints, shader variants, inactive regions and the include tree. Install it from the Visual Studio Marketplace or Open VSX.
